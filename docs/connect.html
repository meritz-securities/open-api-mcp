Claude 웹·모바일, ChatGPT 웹 — 조회 전용 터널

  

    
이 구성은 조회 전용으로만 쓰십시오. 두 서비스 모두 커스텀 커넥터의 인증 옵션이
    OAuth 아니면 없음뿐이라, 주소의 난수 경로가 사실상 유일한 접근 통제입니다. 그 주소는 연결한 AI 서비스 쪽에
    커넥터 설정으로 저장되며 이용자가 지우기 전까지 남습니다. 주소를 알게 된 사람은 그 계좌의 잔고·보유종목을
    조회할 수 있습니다.

    주문·환전을 쓰시려면 터널이 아니라 위의 실행 파일 등록 방식을 쓰십시오. 아래 명령은 주문·환전을
    막은 상태로 고정되어 있습니다.

    
ChatGPT 데스크톱 앱은 터널이 필요 없습니다. 위의 실행 파일 등록 방식을 쓰십시오.
    PC를 켜 두어야 하고, 무료 터널은 주소가 매번 바뀝니다. 아래 명령은 bash·zsh 기준입니다.


    
1. 앱키를 파일에 둡니다

    
명령줄에 두면 셸 기록 파일과 프로세스 목록에 남습니다. 아래 내용을 편집기로
    ~/meritz/.env 에 저장한 뒤 권한을 좁히십시오.

    

    
mkdir -p ~/meritz && chmod 600 ~/meritz/.env


    
2. 서버를 조회 전용 HTTP 모드로 실행

    

    
서버는 127.0.0.1 에만 바인딩합니다. 포트를 공유기에서 직접 열어 주지 마십시오.
    페이지를 새로 열 때마다 난수가 바뀝니다.


    
3. 터널 열기 (둘 중 하나)
cloudflared tunnel --url http://127.0.0.1:8765     # 계정 없이 임시 주소
ngrok http 8765                                     # ngrok 계정 필요


    
4. 커넥터에 넣을 주소

    
Claude: 설정 → 커넥터 → 커스텀 커넥터 추가 → 주소 입력, 인증은 비워 둠 (전 요금제. 휴대폰 앱·음성 모드에서도 같은 연결을 씁니다).

    ChatGPT: 설정 → 커넥터 → 고급 → 개발자 모드 → 만들기 → 주소 입력, 인증 없음 (유료 요금제, 웹에서 설정. 음성 모드에서는 도구가 호출되지 않습니다).

    쓰고 나면 터널과 서버를 닫고, 커넥터 설정에서 그 주소를 지우십시오.
