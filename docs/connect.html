Claude 웹·모바일, ChatGPT 웹 — 내 PC의 서버를 터널로

  

    
두 서비스는 HTTPS 주소로 접근되는 서버만 받습니다. 아래 두 명령을 각각 다른 터미널에서 실행한 뒤, 표시된 터널 주소를 커넥터에 넣으십시오.

    
PC를 켜 두어야 하고, 무료 터널은 주소가 매번 바뀝니다. 주소를 아는 사람은 누구나 접근할 수 있으므로 아래 난수 경로를 그대로 쓰세요. 페이지를 새로 열 때마다 난수가 바뀝니다.

    
1. 서버를 HTTP 모드로 실행

    
2. 터널 열기 (둘 중 하나)
cloudflared tunnel --url http://127.0.0.1:8765     # 계정 없이 임시 주소
ngrok http 8765                                     # ngrok 계정 필요

    
3. 커넥터에 넣을 주소

    
Claude: 설정 → 커넥터 → 커스텀 커넥터 추가 → 주소 입력, 인증은 비워 둠 (전 요금제. 휴대폰 앱·음성 모드에서도 같은 연결을 씁니다).

    ChatGPT: 설정 → 커넥터 → 고급 → 개발자 모드 → 만들기 → 주소 입력, 인증 없음 (유료 요금제, 웹에서 설정. 음성 모드에서는 도구가 호출되지 않습니다).
